# Google Apps Script + Google Sheets (ঐচ্ছিক) — ধাপে ধাপে

এটি **না করলেও** অ্যাপ পুরো ঠিকমতো চলে। করলে যা পাবেন:
- পছন্দের সেটিং (ডিফল্ট ভাষা, ফন্ট) আপনার Google Sheet-এ ব্যাকআপ ও ফিরিয়ে আনা
- **আপনি নিজে "Google Sheets-এ সংরক্ষণ" চাপলে** OCR-এর লেখা Sheet-এ জমা
- (ঐচ্ছিক, ডিফল্টে বন্ধ) বেনামী ব্যবহার-পরিসংখ্যান: শুধু মোড, পৃষ্ঠা-সংখ্যা, সফল কি না, ভাষা, সময়

ছবি/PDF কখনো যায় না। কোনো পাসওয়ার্ড বা API Key অ্যাপের কোডে নেই। খরচ নেই (সাধারণ Google অ্যাকাউন্টই যথেষ্ট)।

## ধাপ ১: Google Sheet বানান
1. <https://sheets.new> খুলুন। নাম দিন, যেমন **বাংলা OCR Studio ডেটা**।

## ধাপ ২: Apps Script-এ কোড বসান
1. Sheet-এর উপরের মেনুতে **Extensions (এক্সটেনশন) → Apps Script** চাপুন।
2. যে `Code.gs` খুলবে তার সব লেখা মুছে ফেলুন।
3. এই প্রজেক্টের **`gas/Code.gs`** ফাইলের সব লেখা কপি করে সেখানে পেস্ট করুন।
4. উপরের **Save (💾)** চাপুন।

## ধাপ ৩: Sheet-এর ট্যাব বানান (একবার)
1. উপরের ফাংশন-তালিকা থেকে **`setup`** বাছুন, তারপর **Run (▶)** চাপুন।
2. প্রথমবার অনুমতি চাইবে: **Review permissions** → আপনার অ্যাকাউন্ট → "Google hasn’t verified this app" দেখালে **Advanced → Go to … (unsafe)** → **Allow**।
   (এটি আপনার নিজের লেখা/বসানো Script, তাই এই সতর্কতা স্বাভাবিক। Script শুধু এই Sheet-এ লেখা-পড়ার অনুমতি চায়।)
3. Sheet-এ **Settings, Usage, Results** নামে তিনটি ট্যাব তৈরি হবে।

## ধাপ ৪: Web App হিসেবে Deploy করুন
1. ডানদিকে উপরে **Deploy → New deployment**।
2. Type (গিয়ার আইকন) থেকে **Web app** বাছুন।
3. **Execute as: Me (আমি)**
4. **Who has access: Anyone (যে কেউ)** ← এটি জরুরি, না হলে অ্যাপ ব্যবহার করতে পারবে না।
5. **Deploy** চাপুন → **Web app URL** কপি করুন। এটি দেখতে এমন:
   `https://script.google.com/macros/s/AKfycb…/exec` (শেষে `/exec` থাকতে হবে)

## ধাপ ৫: অ্যাপে URL দিন
1. অ্যাপের উপরে **Settings** → **১. Google Sheets সংযোগ**-এ URL পেস্ট করুন।
2. **URL সংরক্ষণ** → **সংযোগ পরীক্ষা**। "সংযোগ ঠিক আছে ✔" এলে কাজ শেষ।
3. (ইচ্ছা হলে) Settings-এ পছন্দ বেছে **Sheets-এ ব্যাকআপ** চাপুন।

URL সবার জন্য অ্যাপে বসিয়ে দিতে চাইলে `src/services/configuration.js`-এর `appsScriptUrl`-এ লিখে GitHub-এ Commit করুন। (ব্যবহারকারী Settings থেকে নিজের URL দিলে সেটিই আগে ধরা হবে।)

## Code.gs বদলালে
**Deploy → Manage deployments → ✎ (Edit) → Version: New version → Deploy**। (URL একই থাকে।)

## নিরাপত্তা — সৎভাবে জেনে রাখুন
- Web App "Anyone" হওয়ায় URL জানা যে কেউ অনুরোধ পাঠাতে পারে। তাই URL **প্রকাশ্যে ছড়াবেন না**।
- লগইন নেই। প্রতিটি ব্রাউজার একটি এলোমেলো ৩২-অক্ষরের **clientId** বানায়; Script শুধু সেই clientId-র তথ্য দেখায়/মোছে। clientId আন্দাজ করা কার্যত অসম্ভব, কিন্তু কেউ তা জেনে গেলে সেই ব্রাউজারের তথ্য দেখতে পারবে।
- **Sheet-এর মালিক (আপনি) সংরক্ষিত সব লেখা Sheet-এ সরাসরি দেখতে পান।** অন্যদের জন্য অ্যাপ চালালে তাদের সামনে এটি স্পষ্ট জানান। অ্যাপে সংরক্ষণের আগে সম্মতি চাওয়া হয় এবং Settings-এ নিজের তথ্য মুছে ফেলার বাটন আছে।
- সুরক্ষা-ব্যবস্থা Script-এ: clientId-র ছাঁচ যাচাই, কাজের তালিকা সীমিত (Whitelist), অনুরোধ ১২০,০০০ অক্ষরের মধ্যে, লেখা ৪৫,০০০ অক্ষর পর্যন্ত, প্রতি clientId-তে ১০ মিনিটে ৬০টি অনুরোধ ও সর্বোচ্চ ২০০টি সংরক্ষিত ফল, Sheet-এর ঘর "সাধারণ লেখা" ফরম্যাটে লেখা হয় (যাতে `=…` সূত্র হিসেবে চলে না), ভেতরের ত্রুটির বিবরণ বাইরে যায় না।
- Google-এর দৈনিক Apps Script সীমা (Quota) আছে; ব্যক্তিগত ব্যবহারে সাধারণত যথেষ্ট।

## সমস্যা হলে
| লক্ষণ | কী করবেন |
|---|---|
| "ঠিক উত্তর আসেনি" | Deploy-এ **Who has access = Anyone** আছে কি, URL শেষে `/exec` আছে কি দেখুন |
| "সংযোগ করা যায়নি" | ইন্টারনেট দেখুন; URL পুরো কপি হয়েছে কি দেখুন |
| Code বদলেও আচরণ একই | **New version** দিয়ে আবার Deploy করুন |
| "অনেক বেশি অনুরোধ" | ১০ মিনিট অপেক্ষা করুন |
| "সংরক্ষণের সীমা পূর্ণ" | Settings → আমার সংরক্ষিত ফল থেকে পুরনোগুলো মুছুন |
